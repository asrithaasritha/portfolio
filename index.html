FinPulse: real-time transaction processing and anomaly detection

A platform that simulates an Account Aggregator framework. It ingests high-velocity transaction streams, flags unusual activity and generates financial insights.

The main challenge is surviving traffic bursts without overwhelming the database. Redis queues separate ingestion from persistence, so writes can be batched and processed asynchronously. LLM analysis runs only when an anomaly rule fires, which keeps API cost down.

I’m measuring: throughput, p50, p95 and p99 latency, database CPU, queue delay, token use and recovery from failures.

E-commerce retention and revenue strategy

An analysis of 99,000+ orders. Month-1 repeat purchase was below 1%. Late deliveries averaged 2.27 stars against 4.29 for on-time ones (Welch’s t-test, Cohen’s d 1.71, p < 0.001). At-risk customers were 23% of the base but 34% of revenue, which led to an illustrative win-back plan with a modelled 243% ROI and a recommendation to A/B test first.
